# GadaaBot 2.0 system card
**Intended use:** general health information and school-subject explanations in Afaan Oromoo for students,
teachers, parents and community members. **Not intended for:** diagnosis, dosing, emergencies, legal or financial advice.
**Safeguards:** ingress danger-sign screen with urgent-care message; health disclaimer; citations to sources;
abstention when retrieval finds nothing reliable; no medicine doses; rate limiting; feedback buttons.
**Known limitations:** some sources were written for other audiences (for example travellers from the United
States); statistics can be outdated; answers can still be wrong (2.7% confidently wrong on the test set by the
judge); informal spelling lowers quality slightly; the danger-sign list has not been clinically validated.
**Evaluation:** see the paper (184 reviewed held-out questions, blind two-annotator human study).
